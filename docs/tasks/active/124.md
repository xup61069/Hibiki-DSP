# Issue 124 handoff

## Objective

Harden the same-machine takeover protocol in `docs/ai/MULTI_AGENT.md`: before any
session pushes to or takes over a branch it did not start, it must (1) run
`git worktree list` and confirm no local worktree currently holds that branch
checked out — a held worktree means another session may carry unpushed work — and
(2) announce the intended takeover in a comment on the owning Issue before touching
the branch.
