# Issue 28 handoff

## Objective

Strengthen the WinUI source accessibility gate so every interactive `MainWindow.xaml`
control has an explicit `AutomationProperties.Name`, instead of relying only on a short
list of anchor strings. Add a bounded self-test for the scanner without claiming target UI
Automation evidence.

- The gate scans every `Button`, `ComboBox`, `Slider`, `ToggleSwitch`, `CheckBox`, `TextBox`,
  and `NumberBox` opening element in `MainWindow.xaml`.

  location; current controls pass.
- A bounded self-test covers a valid control, a missing name, multiline attributes, and an
  unrelated non-interactive element without modifying the repository.

  records source-only coverage.
