# Foundation handoff

## Objective

建立可公開、可重建、可跨 AI 接手的 Hibiki DSP monorepo，逐步把 Audio Scene OS 的
driver、RT graph、ASIO、VST3、瀏覽器與校正功能落成可驗收模組。

## Completed

- Public documentation, component license map, stable distribution profile, JSON schemas and
  source-only paid-release policy.
- C++20 static library with Scene validation, volume reconciliation, ISO compensation boundary
  and device switch transaction state machine.
- CMake/CTest build and PowerShell doctor/probe/verify/docs/source-policy gates.
- SPEC-0003 draft boundary, SPEC-0004 AI handoff contract, SPEC-0005 source-only release contract
  and ADR-0003 release decision.
- Immutable RT graph snapshot with 2/6/8-channel mapping and non-allocating interleaved mixing.
- Versioned IPC frame codec, Apache C driver ABI, portable driver validator, ASIO stream model,
  VST quarantine model and MV3 tab-capture source prototype.
- Caller-owned output ring buffer, clock-drift estimator and bounded linear SRC prototype.
- Source-only PowerShell installer bootstrapper with manifest/hash dry-run gate.
- Easy Scene factory, acoustic-anchor phon mapping, PEQ/text exporters and float-WAV IR writer.
- `AudioEngineModel` facade with graph transaction, Windows volume notification and one final
  Group Master gain in the RT process call.
- Windows `IAudioEndpointVolume` broker and `IMMNotificationClient` watcher with bounded,
  non-blocking callback snapshots, dB read-back and event-context GUID writes.
- Worker-side `DeviceRecoveryCoordinator` with monotonic event ordering, transactional rebind and
  safe-start dB plus mute after endpoint invalidation or Audio Service restart.
- Parameterized ISO 226:2023 formula with caller-supplied legal parameters and a tested 1 kHz
  invariant; no licensed coefficient table is embedded.
- MS-PL WaveRT endpoint control-state core validates 2/6/8-channel LPCM, Q16.16 dB safety,
  mute/generation ordering and actuator semantics; it is portable-testable but not a loadable
  PortCls miniport.
- Persistent linear SRC carries phase and one boundary frame across blocks and rejects output
  buffers that would force partial input consumption.
- VST host model enforces trusted/certified descriptors and bounded heartbeat watchdog quarantine;
  the source-only worker now runs bounded Hello/Heartbeat/ProcessBlock passthrough/Shutdown IPC,
  while the real SDK/plugin host remains pending.
- `AudioSessionRegistry` uses endpoint plus session-instance identity, keeps user lane/output
  bindings across metadata refresh, and treats PID as advisory only.
- Windows `IAudioSessionManager2` watcher enumerates sessions on the worker and keeps
  `OnSessionCreated` callback allocation-free; no live physical endpoint enumeration has been
  exercised in this machine's test run.
- Worker-side `ISimpleAudioVolume` dB/scalar conversion, GUID-tagged writes and readback are
  implemented; exclusive-mode and vendor ASIO are still explicit bypass paths.
- `OutputSinkModel` connects bounded clock drift ratio to persistent SRC without allocation in
  the audio-side process call; real per-device clock soak tests remain pending.
- Optional `hibiki_asio_native` source target builds against the pinned local ASIO SDK and
  implements COM discovery, stable CLSID, ASIO buffer/rate/channel callbacks and registry
  entrypoints; the target remains off in public source-only CI.
- `SceneSafetyController` implements and tests peak-triggered attenuation, 100 ms action
  coalescing, manual Windows-volume override detection and safe scene-baseline restoration.
- `OutputCrossfade` implements and tests allocation-free equal-power handoff for supported
  LPCM layouts; physical sink clock and hotplug soak remain hardware work.
- `Vst3SandboxProcess` provides Windows Job Object process containment and explicit watchdog
  quarantine; the bounded worker IPC is present, while SDK/plugin certification remains pending.
- MV3 extension now emits user-gesture-gated `HIBT` AudioWorklet packets to an optional
  localhost bridge while preserving local playback when no receiver is running.
- `hibiki_tab_bridge_contract` validates HIBT packets and now includes a Windows loopback-only
  WebSocket listener; its queue can feed the selected graph lane through a no-allocation adapter,
  while denoising model provenance remains pending.
- `driver/wdk/hibiki_property_adapter.cpp` provides an MS-PL-only WDK property-dispatch scaffold
  over the portable endpoint core; it is source-checked but not a built or signed driver.
- `hibiki_asio_transport_v1` defines an Apache-2.0 fixed-layout SPSC shared-memory ring. The
  optional native ASIO DLL publishes eight-channel Float32 blocks after host callbacks, while
  `AsioTransportConsumerV1` owns the stable mapping and provides an allocation-free engine-side
  pop. A missing or mismatched mapping leaves ASIO usable but explicitly detached.
- `AudioEngineModel::process_asio_transport` now consumes one ring block into a selected Lane,
  executes the immutable graph and Group Master, and restores the caller's lane view; a Windows
  contract test exercises mapping creation, producer publication and processed output.
- `TabCaptureQueueV1` copies validated browser packets into a bounded four-slot SPSC queue from the
  WebSocket callback, exposes dropped-block telemetry, and gives a no-allocation pop; the
  `process_tab_capture_lane_v1` adapter now drives the selected graph lane and Group Master.
- `AudioEngineModel::process_lane_block` is now the shared caller-owned block entry for ASIO,
  TabCapture and future Virtual Mic sources, preserving the same immutable graph and Group Master
  semantics without coupling platform bridges to the RT thread.
- `WindowsWasapiOutputV1` plus `WindowsWasapiSinkWorkerV1` add a shared-mode Float32 physical
  render worker: one COM apartment owns bind/start/render/unbind, a bounded SPSC receives blocks,
  silence fills underruns, and `OutputSinkModel` applies worker-side persistent SRC plus queued
  clock observations. Invalid format/device paths fail closed; real endpoints remain unexercised;
  the graph RT thread never invokes this COM boundary.
- `vst3_worker_protocol.hpp`/`.cpp` define and test the fixed little-endian supervisor/worker frame
  ABI, including exact ProcessBlock payloads and NaN/Inf rejection; named-pipe transport and the
  source-only worker executable are now present, while SDK dispatch and latency compensation remain open.
- `Vst3WorkerPipeV1` is now wired into `Vst3SandboxProcess` launch/stop lifecycle, passing an
  optional `--hibiki-pipe` argument and exposing bounded control-plane wait/send/receive; no
  plugin SDK worker is bundled or claimed.
- `VirtualMicRouteModel` provides a tested privacy/reference contract for future Virtual Mic
  routing (1/2 channels, fixed rates, mute default, caller-owned copy); `process_virtual_mic_lane_v1`
  applies that gate before the shared graph, and it is still not AEC/NS or a signed driver.
- `EasyControlSession` provides a UI-independent fail-closed One-Tap Enhance contract, explicit
  Easy/Expert mode, scene selection and active output-group identity for future WinUI rendering.

## Known limitations

- Current development machine is Windows build 22631, below the driver target build 26100;
  user-space contract tests pass but this is not driver-target evidence.
- The Windows broker/watcher callbacks are unit-exercised only; no real Hibiki endpoint,
  physical sink rebind or Audio Service restart has been exercised.
- No WaveRT-backed endpoint or physical sink delivery for the ASIO ring, WinUI app, real VST3 SDK
  plugin host, calibration compiler or signed installer exists yet.
  The optional ASIO COM transport and shared-memory boundary are unsigned developer code and do
  not themselves provide physical I/O.
- ISO formula parameters and contour values are caller-supplied; no licensed standard data or
  formal conformance oracle is embedded.
