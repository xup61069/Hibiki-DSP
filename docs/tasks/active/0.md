# Foundation handoff

## Objective

建立可公開、可重建、可跨 AI 接手的 Hibiki DSP monorepo，逐步把 Audio Scene OS 的
driver、RT graph、ASIO、VST3、瀏覽器與校正功能落成可驗收模組。

## Known limitations

- Current development machine is Windows build 22631, below the driver target build 26100;
  user-space contract tests pass but this is not driver-target evidence.
- The Windows broker/watcher callbacks are unit-exercised and the opt-in catalog probe sees local
  endpoint metadata; no real Hibiki virtual endpoint, physical sink rebind or Audio Service
  restart has been exercised.
- No WaveRT-backed endpoint or physical sink delivery for the ASIO ring, WinUI SDK/build and
  accessibility validation, Scene-wired VST3 SDK plugin host, or signed installer exists yet;
  the bounded calibration compiler is a control-plane baseline and the optional SDK
  processor is a worker-side single-main-bus boundary only.
  The optional ASIO COM transport and shared-memory boundary are unsigned developer code and do
  not themselves provide physical I/O.
- ISO formula parameters and contour values are caller-supplied; no licensed standard data or
  formal conformance oracle is embedded.
