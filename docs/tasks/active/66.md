# Issue 66 handoff

## Objective

Fix the glob-to-regex conversion in `tools/context-pack.ps1`. Patterns such as `src/**/file.cpp`
must match both `src/file.cpp` and deeper descendants; the current replacement emits a mandatory
extra separator and misses direct children.

## Acceptance

- Preserve exact-path and single-star semantics: `*` and `?` do not cross `/`.
- Correct recursive semantics: `**/` matches zero or more directory segments, and `/**` matches
  descendants without requiring an extra separator.
- Add `-SelfTest` with bounded in-memory fixtures covering exact, single-star, recursive direct/deep
  matches, and rejection of near misses; self-test must not read or write repository files.
- Preserve context-pack output and deduplication behavior outside corrected glob matching.
- Add anonymous evidence and run handoff, docs, source-policy, source-only, and `git diff --check`
  gates; wait for actual CI results.

## Completed

- Created Issue #66 after finding the recursive glob direct-child gap in the existing context-pack
  converter and confirming no active scope claims `tools/context-pack.ps1`.
- Created this schema-v2 claim from latest `origin/main` `99ef1ea` in an independent worktree.
- Baseline reproduced the bug: `src/**/*.cpp` matched `src/hub/foo.cpp` but not `src/foo.cpp`, and
  the pre-change script rejected `-SelfTest` as an unknown parameter.
- Replaced chained string replacements with a character-wise glob parser that treats `**/` as zero
  or more directory segments, `**` as recursive content, and `*`/`?` as single-segment wildcards.
- Added 12 bounded in-memory self-test cases covering exact, single-star, question-mark, recursive
  direct/deep, suffix-recursive, and near-miss behavior.
- Added anonymous evidence at `evidence/0000-foundation/context-pack-glob-v1.json` anchored to
