# Issue 72 handoff

## Objective

Add `sync_timeline_store_to_scheduler_v1`: a bounded, deterministic adapter that
loads every timeline from a `Vst3TimelineFileStoreV1` directory into a
`Vst3SceneAutomationSchedulerV1` through the existing `upsert_timeline` path,
connecting the merged Issue #63 store and Issue #22 scheduler without new storage
formats, IPC, schemas or threading.

## Acceptance

- Empty store yields zero loaded / zero skipped and leaves the scheduler untouched.
- Valid stored timelines appear in the scheduler afterwards (readable via
  `timeline_snapshot`).
- Per-entry failures (io_error, parse_error, upsert rejection such as a full
  scheduler) increment `skipped`, never abort the run, and leave prior scheduler
  entries unchanged.
- Closed store returns invalid_argument with a zeroed result.
- No CMakeLists change; no IPC frame, schema file, RT-thread, driver or
  permanent-identity change; single-writer control plane, no locking added.
