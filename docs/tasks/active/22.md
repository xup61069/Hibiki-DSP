# Issue 22 handoff

## Objective

Bind the merged Issue #14 supervisor timeline editor (`Vst3TimelineEditorV1`) to the
Scene automation scheduler: bounded edit transactions against one stored timeline slot
(`begin_timeline_edit`, `editing_timeline`, `commit_timeline_edit`,
`cancel_timeline_edit`) plus a `timeline_snapshot` readback accessor. This closes the
remaining headless gap of the SPEC-0008 supervisor editing item; a real UI surface and
complete automation scheduling remain open.

## Acceptance

- Begin/edit/commit/cancel lifecycle bound to one timeline ID; double-begin and
  unknown-ID begin fail closed.
- Commit swaps only the edited slot's stored snapshot and only after the shared
  timeline validation passes; cancel restores the pre-edit snapshot verbatim.
- `remove_timeline` refuses while that slot is under edit; `clear()` deterministically
  aborts any active edit.
- Committed result is observable via `timeline_snapshot` and reaches a prepared lane
  through the unchanged `activate_scene` path.
- No IPC frame, schema file, RT-thread, driver or permanent-identity change; the
  control plane stays single-writer with no new locking.
