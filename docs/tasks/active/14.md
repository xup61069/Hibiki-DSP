# Issue 14 handoff

## Objective

Implement a fail-closed supervisor-side editing transaction model for VST3 parameter
timelines (`Vst3TimelineEditorV1`) in the unclaimed `vst-host/` lane. It closes part of
the open "supervisor UI timeline editing" item recorded in SPEC-0008 as a headless
control-plane model that a future UI can bind to; full UI editing, cross-version plugin
state persistence and complete automation scheduling remain open.

## Acceptance

- Editor mutations fail closed on invalid input and never publish an invalid snapshot.
- One value per (parameter_id, sample_position); upsert replaces instead of duplicating.
- Commit validates against the existing `validate_vst3_parameter_timeline_v1` contract
  (256 events, <=16 parameters, sorted order, finite normalized values) before swapping
  the published snapshot; discard reverts the draft.
- Contract tests cover capacity, ordering, duplicate replacement, invalid values,
  stale-draft rejection and rollback behavior.
- No IPC frame, schema file, RT-thread, driver or permanent-identity change.
