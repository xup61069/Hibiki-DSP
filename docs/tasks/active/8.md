## Known limitations

- This probe is an explicitly user-invoked user-space Windows control-plane
  check. It does not prove a Hibiki virtual endpoint, WaveRT/PortCls driver,
  physical DSP playback, per-App routing, HLK, or Microsoft signing.
- `-WriteTest` temporarily changes the local default endpoint volume by about
  3 dB and must restore it; it must never be run implicitly.
- The local machine may lack the locked Windows 11 24H2 / VS 2026 / SDK-WDK
  toolchain, so target WinUI, driver, hardware, and signing claims remain
  unverified unless the required CI/target evidence exists.
