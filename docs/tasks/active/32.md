drift. The extension must retain only the bounded tab-capture/offscreen permissions, localhost
bridge host permission, and self-only extension-page CSP required by SPEC-0009.

## Acceptance

- The gate rejects permissions outside `activeTab`, `tabCapture`, and `offscreen`.
- The gate rejects host permissions outside the exact `http://127.0.0.1/*` loopback boundary
  and rejects wildcard remote hosts.
- The gate requires exact self-only extension-page CSP with the fixed localhost WebSocket
  endpoint and rejects remote script/eval policy drift.
- A bounded `-SelfTest` covers allowed manifest, dangerous permission, broad host, and
  remote-code/CSP cases without modifying the repository.
- SPEC-0009 documents the least-privilege/CSP invariant and anonymous evidence records only
  source-only coverage.
- Required local gates and GitHub Actions verify pass. No browser runtime, physical audio,
  driver, HLK, or signing claim is made.
