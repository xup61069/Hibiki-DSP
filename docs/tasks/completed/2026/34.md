# Issue 34 handoff

## Objective

required tokens anywhere in the file. The gate must fail closed on missing or misplaced section
directives while keeping the external WDK/Inf2Cat package path explicit.

- The source gate strips comments and validates required directives in their expected INF sections:
  Version, Manufacturer/NTamd64, install mapping, CopyFiles, service, and ServiceBinary.
