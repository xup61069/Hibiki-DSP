## Objective

Provide the MS-PL PortCls `IMiniportWaveRT` and `IMiniportWaveRTStreamNotification` source boundary scaffold in `driver/wdk/` that bridges Windows audio miniport stream/property dispatch to the portable `endpoint_topology_v1`, `wavert_stream_v1`, and `wavert_endpoint_state_v1` cores, preserving the license, non-allocating execution, and strict separation from GPL user-space.

## Acceptance

- Implement `IMiniportWaveRT` (`HibikiMiniportWaveRtV1`) and `IMiniportWaveRTStreamNotification` (`HibikiMiniportWaveRtStreamV1`) COM interface adapters in `driver/wdk/` conforming to standard WDK PortCls miniport definitions.
- Wire stream allocation, position querying, clock register handling, notification event registration, and state transitions to `wavert_stream_v1` with spinlock synchronization.
- Wire property handlers to `hibiki_property_adapter.cpp` and `wavert_endpoint_state_v1`.

- Generate anonymous evidence file and pass all local gates.
