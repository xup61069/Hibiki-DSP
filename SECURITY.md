# Security policy

Do not report driver vulnerabilities, signing incidents or private data in a
public issue. Use GitHub Private Vulnerability Reporting when enabled, or
contact the maintainer listed in the repository security settings.

Never put production signing keys, Gumroad credentials, Partner Center tokens,
customer data, private calibration captures or ISO licensed material in an
issue, pull request, AI prompt or CI log. A compromised release key requires
immediate revocation, clean rebuild, re-signing and a security advisory.
