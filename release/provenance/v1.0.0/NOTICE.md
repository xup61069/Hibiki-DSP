# Hibiki DSP v1.0.0 third-party notices

This is a source-only release. It distributes no third-party binary, driver,
installer, package, or release asset.

## Component license map

- `src/`, `apps/`, `asio/`, `vst-host/`, `extensions/`, and `installer/` are
  GPL-3.0-only Hibiki user-space source.
- `driver/` is the MS-PL SYSVAD-derived driver boundary.
- `sdk/` and `schemas/` are Apache-2.0 public contracts and SDK material.
- `docs/` is CC-BY-4.0 documentation.
- `tests/fixtures/` is CC0-1.0 synthetic test material.

The complete component license texts are retained in `LICENSES/`. The
repository's current third-party inventory, including source locations,
versions or commit pins, licenses, purposes, and redistribution obligations,
is `THIRD_PARTY.yml`. Obtain external dependencies from their stated sources
and preserve their notices when they are bundled outside this source-only tag.
